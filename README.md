# Skaner GPW

Automatyczny skaner spółek z GPW. Uruchamia się sam w dni sesyjne rano i po sesji,
a wynik publikuje jako stronę (GitHub Pages) – wygodną na telefonie.

Moduły: 🔥 panika, 🚀 wystrzał (zlecenie z limitem na 61,8% korekty), 📉 5 spadków,
📉 RSI2<5 w trendzie, 📈 wybicie na szczyt 120 sesji, 🌀 CHOP+Stoch RSI, ⛔ ostrzeżenia, ⭐ spółki dobrze reagujące.
Przy każdym sygnale: gdzie kupić, gdzie sprzedać, stop awaryjny.

Uruchomienie lokalne: `pip install -r requirements.txt` i `python skaner.py`.

Narzędzie pomocnicze, nie rekomendacja inwestycyjna.
